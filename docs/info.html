关于 GMP 出题引擎
GMP 出题引擎 是一款专为初中生打造的极简数学练习工具。我们摒弃了传统题库的臃肿与繁琐，将核心算法与现代化的前端交互完美结合，旨在为你提供最纯粹、最高效的数学思维训练体验。
我们的核心理念
  • 算法驱动： 告别死记硬背，题目数据每次运行自动随机生成，同一题型永远不同的数字。
  • 极客交互： 采用终端界面的打字机特效，让做题就像在调试一段精妙的程序。
  • 极速响应： 采用 ES6 模块化按需加载架构，首屏加载几乎是瞬时的。
  • 随时随地： 无需下载安装，只要有浏览器，打开网页即可练习。
功能特点
目前引擎内置了七年级数学的巡逻车坐标与行程问题，支持普通模式与终端模式自由切换。你可以一键生成题目，在思考完毕后随时查看详细解析。
技术架构
本项目完全基于纯前端技术构建（HTML5 / CSS3 / Vanilla JS），无任何后端依赖。通过动态 `import()` 实现了真正的按需加载，大幅减少带宽消耗。即使你直接在本地双击打开 HTML 文件，内置的降级方案也能保证所有功能完美运行。
